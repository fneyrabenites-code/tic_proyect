¿Que es Open5GS?

Open5GS es un proyecto avanzado de código abierto diseñado para construir y administrar su propia red móvil NR/LTE. Ya sea que esté configurando una red privada para pruebas, investigación o implementación, Open5GS ofrece una solución robusta para configurar redes 5G (NR) y LTE (evolucionadas).

Caracteristicas y componentes

Características principales

  • Modular:
    Permite combinar distintas implementaciones de código abierto, incluso en diferentes versiones. Por ejemplo, un mismo núcleo con distintas antenas.
  • Contenedores (Docker):
    cada servicio (eNB, gNB, funciones del core 5G) corre aislado, lo que facilita el despliegue y evita conflictos de dependencias.
  • Stacks por caso de uso:
    Se agrupan servicios en “stacks” definidos con Docker-Compose, por ejemplo Open5GS + srsRAN.
  • Reproducible:
    Los parámetros globales (banda, canal, IPs fijas, IMSI y claves SIM) están en archivos de entorno centrales, y la base de datos de suscriptores se crea desde cero en cada arranque.
  • Interfaz web (WebUI):
    permite configurar, iniciar y detener stacks, y ver los contenedores y sus logs con indicadores de estado por colores.
  • Multigeneración:
    se probó en 2G, 4G (con VoLTE) y 5G SA.
  • Compatible con equipos reales:
    se evaluó con cinco smartphones comerciales y un módem.

Usos del Open5G

  • Investigación en redes móviles:
    Permite hacer experimentos rigurosos y reproducibles, integrando diferentes componentes de radio y de core con equipos de usuario reales.
  • Probar ideas para futuras generaciones de redes:
    Por ejemplo nuevos protocolos o configuraciones.
  • Seguridad:
    El código abierto permite revisar y modificar las implementaciones para simular ataques, evaluar métodos de detección y buscar vulnerabilidades en los estándares actuales.
  • Probar la compatibilidad de celulares y módems:
    con redes privadas 4G y 5G. Es lo que hicieron los autores con teléfonos Samsung, OnePlus, Google Pixel, iPhone y otros.
  • Escenarios específicos:
    Los autores mencionan, por ejemplo, probar vulnerabilidades concretas y evaluar escenarios de roaming.
  • Comparar combinaciones de software:
    Por ejemplo Open5GS con srsRAN frente a Free5GC con OAI-RAN, cambiando de stack rápidamente.

Descargar e instalar

Requisitos

  • Host con Ubuntu 22.04 LTS (recomendado)
  • 8+ núcleos de CPU, 32 GB de RAM, 200 GB de almacenamiento
  • Acceso a Internet y permisos sudo

Como descargar el Ubuntu 22.04 LTS

1. Entrar a la página oficial

Abre releases.ubuntu.com/22.04 (enlace directo a la versión 22.04, porque ubuntu.com/download ofrece la más reciente).

2. Descargar la ISO

  • Desktop (64-bit): ubuntu-22.04.x-desktop-amd64.iso, unos 4.5 GB. Es la versión con interfaz gráfica.
  • Server: solo para servidores, sin entorno gráfico.

Hasta donde sé, la última revisión es 22.04.5. Descarga la que aparezca en la página.

3. Verificar la descarga (opcional)

En PowerShell ejecuta:

Get-FileHash .\ubuntu-22.04.x-desktop-amd64.iso

El resultado debe coincidir con el valor del archivo SHA256SUMS de la página oficial.

4. Instalar Ubuntu

  1. Elige Try or Install Ubuntu.
  2. Selecciona el idioma y pulsa Install Ubuntu.
  3. Configura teclado, conexión y tipo de instalación (junto a Windows o borrando el disco).
  4. Elige zona horaria y crea tu usuario y contraseña.
  5. Espera a que termine y reinicia.

Instalación de open5Gcube

1. Preparación del sistema

Se actualiza Ubuntu con sudo apt update && sudo apt upgrade -y para trabajar con los paquetes al día.

Después se instalan las herramientas base con apt install:

  • git-lfs y curl: descargar el proyecto y archivos.
  • make: ejecutar el Makefile del proyecto.
  • net-tools, openssh-server, ca-certificates, gnupg, linux-tools-common, python3-virtualenv: red, acceso remoto, certificados y soporte de Python.

En la captura, varios paquetes ya estaban en su versión más reciente.

2. Clonación del repositorio

Se descarga el proyecto con git clone https://github.com/open5Gcube/open5Gcube/ (unos 2571 objetos) y se entra con cd open5Gcube.

Ahí están los scripts, el Makefile y la configuración que se usa en el resto del ejercicio.

3. Instalación de Docker

Cada función de red 5G corre como un contenedor, por eso Docker es necesario. El instalador install-docker.sh se ejecuta desde make y pide la contraseña de sudo.

Antes de instalarlo aparece el error docker: command not found, que es normal porque Docker aún no existía.

Luego se ejecutan estos comandos:

  • make systemd-install-unit y sudo systemctl enable o5gc: dejan el servicio open5Gcube habilitado en el arranque.
  • sudo ./scripts/startup.sh: ajusta los buffers de red del kernel y configura una interfaz con la IP 192.168.40.1/24.

4. Construcción de imágenes

Con make docker-build-all se construyen las imágenes Docker de todos los componentes. Puede tardar varias horas.

Imágenes que se ven en las capturas:

  • o5gc/open5gs: núcleo 5G (2.22 GB).
  • o5gc/ueransim: gNB y UE emulados (1.54 GB).
  • o5gc/free5gc (2.48 GB) y o5gc-webui (1.91 GB).
  • mongo y mongo-express: base de datos de suscriptores.

Nota: una captura termina con make: *** [docker-build-all] Error 2, pero las imágenes quedaron creadas y la WebUI funciona después. Si te lo preguntan, ese error no bloqueó lo necesario para el ejercicio.

5. Inicio de la WebUI

Se ejecuta make webui-start. Este comando crea el volumen o5gc-simcard-scripts, copia los scripts de SIM y levanta el contenedor o5gc-webui con docker compose.

Al final aparece Container o5gc-webui Healthy, que indica que arrancó bien.

6. Acceso a la WebUI

Se abre http://127.0.0.1 en el navegador. El panel Service Overview aparece con "0 running" y "Running Stacks: None", porque todavía no hay ningún stack desplegado.

En el menú lateral están los stacks disponibles: oai, oairan, ocudu, packetrusher, srsran y ueransim.

Al lanzar ueransim-open5gs el panel muestra 15 running, con una tarjeta de logs por contenedor: UE, GNB, SMF, UPF, PCF, AUSF, UDM, UDR, NSSF, BSF, SCP y PCRF, entre otros.
